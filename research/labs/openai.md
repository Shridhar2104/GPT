# OpenAI

Founded in December 2015 as a non-profit AI research lab. OpenAI built the GPT series, popularised
RLHF for language models, and launched ChatGPT, which brought LLMs to the mainstream.

- Research index: <https://openai.com/research/>
- News: <https://openai.com/news/>

## Timeline

| Date | Milestone |
|------|-----------|
| Dec 2015 | Founded |
| 2016–2017 | OpenAI Gym · *Concrete Problems in AI Safety* (co-authored) · **PPO** · *Deep RL from Human Preferences* (with DeepMind) |
| Jun 2018 | **GPT-1**: generative pretraining + fine-tuning |
| Feb 2019 | **GPT-2** (1.5B), released in stages over misuse concerns |
| Jan 2020 | *Scaling Laws for Neural Language Models* |
| May 2020 | **GPT-3** (175B) and in-context learning · API launch (Jun) |
| Sep 2020 | *Learning to Summarize from Human Feedback* |
| Jan 2021 | **CLIP** and **DALL·E** |
| Jul 2021 | **Codex** (powers GitHub Copilot) |
| Jan 2022 | **InstructGPT** (RLHF recipe) |
| Sep 2022 | **Whisper** (speech recognition) |
| Nov 2022 | **ChatGPT** |
| Mar 2023 | **GPT-4** |
| May 2023 | *Let's Verify Step by Step* (process supervision) |
| Dec 2023 | *Weak-to-Strong Generalization* |
| Feb 2024 | Sora preview (video generation) |
| May 2024 | **GPT-4o** (native multimodal, real-time voice) |
| Sep 2024 | **o1**: RL-trained reasoning model, test-time compute scaling |
| Dec 2024 | o3 announced · *Deliberative Alignment* |
| 2025 | o3 / o4-mini · GPT-4.5 · Codex agent · gpt-oss open-weight models · **GPT-5** (Aug) |
